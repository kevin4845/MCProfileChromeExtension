MC Profile

Privacy Policy

Last updated: September 11, 2026

Overview

MC Profile is an unofficial Minecraft profile extension for Google Chrome. It allows users to view information about their currently logged-in Minecraft account.

MC Profile does not collect, sell, or store user data on developer-controlled servers.

Information handled by MC Profile

MC Profile accesses information from your existing Minecraft session and the official Minecraft Services API in order to provide its functionality.

This may include:

  • Minecraft username
  • Minecraft UUID
  • Account creation date
  • Username change date
  • Current Minecraft skin
  • Minecraft capes

Authentication information

MC Profile reads the Minecraft authentication cookie from your browser to determine whether you are logged in and to authenticate read-only requests to the official Minecraft Services API.

The authentication token is kept only in memory while the extension is running. It is never stored in Chrome storage, sent to the developer, or stored on developer-controlled servers.

Local storage

MC Profile uses Chrome's session storage to temporarily cache Minecraft profile information for up to 10 minutes. This reduces unnecessary API requests and improves loading speed.

Authentication credentials are never stored in this cache.

Third-party services

MC Profile communicates with the official Minecraft Services API to retrieve Minecraft profile information. Authentication information is sent directly to Minecraft Services for authentication and is not transmitted through any developer-controlled server.

MC Profile also uses MineSkin to display a visual representation of the user's current Minecraft skin. The Minecraft username is included in the request to MineSkin. The Minecraft authentication token is not sent to MineSkin.

Data sharing

MC Profile does not sell, rent, or share user data with advertisers, analytics providers, data brokers, or other third parties for unrelated purposes.

Tracking and analytics

MC Profile does not use analytics, advertising, tracking technologies, browsing history collection, or user profiling.

Data security

MC Profile does not operate a server that stores Minecraft account information. Authentication credentials are kept in memory only and are never persisted by the extension.

Changes to this policy

This privacy policy may be updated if the functionality of MC Profile changes. The date at the top of this page will be updated when material changes are made.

Contact

If you have questions about this privacy policy or MC Profile, please contact the developer through the contact information provided on the MC Profile Chrome Web Store listing.

MC Profile is an unofficial fan-made project and is not affiliated with, approved by, or endorsed by Mojang or Microsoft.
